# 법원 제출용 PDF 자동 분리 도구

> **"준비서면 몇 페이지까지야?" 한 마디면 끝.**  
> 수십 페이지짜리 PDF를 증거별로 손수 나누던 시간, 이제 그만하세요.

---

## 이 도구가 해결하는 문제

전자소송 시스템에 서면을 등록할 때, 법원은 이렇게 요구합니다:

- 준비서면 파일 1개
- 을 제1호증 파일 1개
- 을 제2호증 파일 1개
- …

하지만 실무에서는 준비서면과 증거를 **하나의 PDF로 만들어서** Word나 한글에서 인쇄합니다.  
그걸 매번 PDF 편집 프로그램에서 열어, 페이지 범위를 확인하고, 하나씩 저장하고, 이름 붙이고…

**이 프로그램은 그 과정을 명령어 한 줄로 끝냅니다.**

```

```

---

### AI가 자동으로 해주는 것들

1. `pip install pypdf` 패키지 설치
2. GitHub에서 `split.py` 다운로드
3. PDF 분리 실행
4. 결과 파일을 원본 PDF와 같은 폴더에 저장

**파일 경로와 페이지 수 두 가지만 바꾸면, 나머지는 AI가 전부 처리합니다.**

## 직접 실행하는 방법 (Python이 있는 경우)

### 1단계: 필요한 패키지 설치 (최초 1회)

```bash
pip install pypdf
```

### 2단계: 실행

```bash
python split.py 준비서면파일.pdf --brief-pages 32
```

### 옵션

| 옵션 | 설명 |
|---|---|
| `--brief-pages N` | 준비서면 페이지 수 (이 페이지까지가 준비서면) |
| `--output-dir 폴더명` | 결과 파일 저장 위치 (생략 시 원본 파일과 같은 폴더) |

---

## 자동으로 처리되는 것들

| 상황 | 처리 방식 |
|---|---|
| 을 제1-1호증, 1-2호증, 1-3호증… | `을제1호증.pdf` 하나로 자동 묶음 |
| 을 제2호증-1, 2호증-2 | `을제2호증.pdf` 하나로 자동 묶음 |
| 갑호증 혼합 | 갑제X호증.pdf 별도 생성 |

증거 번호가 바뀌어도, 서브번호(1-1, 1-2…)가 붙어 있어도  
**프로그램이 자동으로 인식해서 같은 번호끼리 묶어줍니다.**

## 작업 흐름

```
Word/한글에서 준비서면 작성
        ↓
증거 이미지 뒤에 붙여 PDF로 저장
        ↓
이 프로그램 실행 (또는 AI에게 부탁)
        ↓
준비서면.pdf + 을제1호증.pdf + 을제2호증.pdf + … 자동 생성
        ↓
전자소송 시스템에 각 파일 등록
```

## 자주 묻는 질문

**Q. 준비서면이 몇 페이지인지 어떻게 알아요?**  
PDF를 열어서 마지막 준비서면 페이지 번호를 확인하면 됩니다.  
보통 입증방법 목록이 끝나는 페이지가 준비서면의 마지막 페이지입니다.

**Q. 증거 번호가 매번 바뀌면요?**  
프로그램이 PDF 안의 텍스트를 읽어서 자동 인식합니다. 번호가 바뀌어도 그대로 씁니다.

[claude.ai/code](https://claude.ai/code) 에서 무료로 시작할 수 있습니다.

## 부가 기능: 용어·증거번호 추천 도우미 (`advisor.py`)

서류 종류와 당사자 지위만 입력하면, **올바른 증거(호증) 부호·번호 규칙과 용어 주의사항**을 알려줍니다.
전자소송에서 자주 틀리는 부분(반소 번호, 항소·상고심 호칭, 내용증명에 호증 안 붙이기 등)을 자동으로 짚어줍니다.

```bash
python advisor.py --type 준비서면 --party 피고 --next 11
python advisor.py --type 항소장   --party 원고 --instance 항소심
python advisor.py --type 반소장   --party 피고 --counterclaim
python advisor.py --type 내용증명 --party 발신인
```

| 옵션 | 설명 |
|---|---|
| `--type` | 서류 종류: 소장 / 답변서 / 준비서면 / 항소장 / 상고장 / 반소장 / 내용증명 |
| `--party` | 당사자 지위: 원고 / 피고 / 독립당사자참가인 / 보조참가인 / 발신인 / 수신인 |
| `--instance` | 심급: 1심(기본) / 항소심 / 상고심 |
| `--counterclaim` | 본소와 반소가 함께 진행 중 |
| `--next N` | 다음에 부여할 호증 시작 번호(직전까지 10호증이면 `11`) |
| `--family` | 가사사건(이혼 등) 보충 안내 추가 |

**핵심 규칙 요약**

| 구분 | 내용 |
|---|---|
| 증거 부호 | 원고=**갑호증**, 피고=**을호증**, 제3자/참가인=**병호증** (제출 주체 기준) |
| 번호 연속 | 한 번 부여한 번호는 변경 X, 새 서면·상급심에서 **이어서** 부여 |
| 항소·상고심 | 부호(갑/을)는 1심 유지, 호칭만 **항소인/피항소인·상고인/피상고인** 병기 |
| 반소 | 부호는 본소 기준 유지(반소원고=본소피고=**을호증**), 번호는 본소와 통합·연속 |
| 내용증명 | 법원 서류 아님 → **호증 번호 안 붙임**, 당사자는 발신인/수신인 |

> ⚠️ 실무 관행 참고용이며 법률자문이 아닙니다. 개별 사건은 담당 재판부·전자소송 안내를 우선하세요.
